# References

Open-source projects that solve parts of what M’AND does. Checked on GitHub on 2026-10-19.

**Licence rule:**
- **GPL projects:** study them for ideas, but don't copy their code. Copying would require M’AND itself to be released under the GPL.
- **Apache-2.0 / Unlicense projects:** code may be reused with attribution.

| Project | What it is | Licence | Useful for |
|---|---|---|---|
| [KDE/kdeconnect-android](https://github.com/KDE/kdeconnect-android) | Android↔computer link app (Kotlin) | GPL-2.0, ideas only | Background survival on aggressive phone makers, notification forwarding, clipboard limits, Share-sheet file sending, battery. Its self-signed-certificate pairing is similar to ours |
| [soduto/Soduto](https://github.com/soduto/Soduto) | Mac (Swift) client for KDE Connect | GPL-3.0, ideas only | How a native Mac app handles the same features |
| [localsend/localsend](https://github.com/localsend/localsend) / [protocol](https://github.com/localsend/protocol) | Cross-platform AirDrop alternative | App: Apache-2.0; the protocol repo reports no licence | Local-network file-transfer UX (accept/decline, progress) |
| [grishka/NearDrop](https://github.com/grishka/NearDrop) | Mac receiver for Android Quick Share | Unlicense | A possible optional extra: receive Quick Share without our app (unofficial protocol) |
| [Genymobile/scrcpy](https://github.com/Genymobile/scrcpy) | Android screen mirroring | Apache-2.0 | Used by M’AND's Screen Mirroring (installed by the user) |
| [SimonAKing/scrcpy-gui](https://github.com/SimonAKing/scrcpy-gui), [kil0bit-kb/scrcpy-gui](https://github.com/kil0bit-kb/scrcpy-gui) | Desktop apps that manage scrcpy | not checked | How to launch and manage scrcpy from an app |
| [Sathvik-Rao/ClipCascade](https://github.com/Sathvik-Rao/ClipCascade) | Clipboard sync | GPL-3.0, ideas only | Workarounds for Android's background clipboard limits |
